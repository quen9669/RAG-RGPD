# Fiche source : CNPD

- **Organisme** : Commission nationale pour la protection des données,
  autorité de contrôle du RGPD au Luxembourg.
- **Site** : https://cnpd.public.lu
- **Format** : PDF (guides, brochures, décisions) et pages web.
- **Vérifié le** : 2026-10-29.

## Conditions d'usage

D'après les [aspects légaux du site](https://cnpd.public.lu/fr/support/aspects-legaux.html),
sauf mention contraire, les documents peuvent être consultés, téléchargés et
imprimés, mais :

- uniquement à titre personnel, pour information, dans un cadre strictement privé ;
- sans les modifier ;
- sans les diffuser en dehors du site.

Aucune licence n'est accordée et toute reproduction demande une autorisation
écrite. Le site ne contient pas de règle sur les robots ; on applique
quand même `robots.txt` et une pause entre les requêtes.

## Conséquences pour le projet

- Les fichiers bruts restent sur la machine locale (`data/raw/` non versionné).
  Aucun document ni extrait de la CNPD n'est publié dans le dépôt GitHub (public).
- Usage strictement personnel, pour l'apprentissage. Toute démonstration
  publique ou mise à disposition de tiers demanderait l'accord écrit de la CNPD.
- Les décisions publiées sont anonymisées : ne jamais tenter de ré-identifier
  les personnes ou organismes concernés.

## Limites

- Les adresses des PDF changent parfois (`/dam-assets/` et `/content/dam/`).
- Les documents anciens (antérieurs à 2018) peuvent précéder le RGPD.
